## Overview

ItsLitho's learning hub collects news, instructions, project ideas, software updates, and background information about designing and 3D-printing lithophanes. It points users toward the free, cross-platform [ItsLitho Lithophane Maker](https://tool.itslitho.com/), which converts images into printable lithophane models.

The page currently indexes **20 resources**:

- **8 featured projects**
- **6 step-by-step guides**
- **6 blog/reference articles**
- **8 entries explicitly marked with update years**

> Category note: “What Is a Lithophane” has no visible category label on the hub, but its URL places it in the ItsLitho Blog section.
